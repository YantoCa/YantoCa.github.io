The Flying Freakshow

Unity C# Game Jam
Visit Page / Play Source Code

Overview

This game was developed by our seven-person team for the Xbox Game Camp Belgium Jam 2026. It is a fast-paced action game where players navigate bizarre acrobatic obstacles under a high-pressure circus banner.

Tech Stack & Tools

  • Engine: Unity 2022.3 LTS
  • Language: C#
  • IDE: JetBrains Rider / Visual Studio
  • Audio: FMOD Engine
  • Version Control: Git / GitHub
  • Target Platform: Windows PC

My Contributions

  • Designed and implemented dynamic player movement and acrobat physics systems.
  • Programmed state-machine-driven camera transitions and particle feedback effects.
  • Integrated audio triggers for responsive music layers during dynamic gameplay.
